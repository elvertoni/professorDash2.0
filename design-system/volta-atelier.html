Marca

A ligadura TC é contorno desenhado, não fonte com kerning. O T entra por trás do C e é cortado pela curva; um vão constante revela a ordem em que as letras se sobrepõem. O C fica inteiro — nenhuma haste o atravessa —, e é por isso que o desenho aguenta redução.

Todas as provas desta página carregam o arquivo real embutido, não um redesenho. Se a marca mudar no assets/, esta página passa a divergir — e é a marca que manda.

Fundos

Lockups

O respiro mínimo em toda a volta é a altura da travessa do T — é a linha tracejada. O lockup horizontal não desce de 160px de largura.

Regras da marca

Carregue o arquivo

Use logo.svg e favicon.svg. Não redesenhe o monograma a partir da Archivo: o corte inclinado da haste e a cunha do braço direito não existem na fonte.

Declare o esquema de cor

O T troca de cor por prefers-color-scheme. Numa superfície escura fora do site, a página precisa declarar color-scheme: dark — sem isso, quem estiver com o sistema no claro recebe um T #141414 sobre fundo escuro.

Respiro é medida, não estimativa

A altura da travessa do T em toda a volta. Nada entra nessa faixa: nem texto, nem borda, nem outra marca.

O vermelho é do C

O acento vive no C e no ponto final do logotipo. Não tinja o T, não aplique gradiente e não troque --color-accent por outro tom.

Uma assinatura por peça

A linha única é a assinatura padrão. A versão com a linha de disciplinas fica para rodapé e crédito — nunca concorre com a principal na mesma peça.

Instalar

Três passos, nesta ordem. Não há etapa de compilação, bundler nem dependência de runtime — o sistema é um arquivo CSS e uma classe no <html>.

As duas fontes

Archivo 700–800 e JetBrains Mono 400–500. Servir local em .woff2 é o que o portfólio faz, e é o que evita o salto de tipografia na primeira pintura; o Google Fonts serve para começar rápido. O par não é decorativo — mono no corpo é o que dá ao sistema a voz técnica que ele tem.

A folha

Copie o último bloco desta página para assets/css/style.css e sirva com ?v=AAAAMMDD. As duas @font-face no topo apontam para ../fonts/ — ajuste o caminho, ou apague-as se estiver usando o Google Fonts do passo anterior.

Cor

Dezesseis tokens semânticos, mais apelidos curtos que os componentes consomem (--ink, --panel, --bone, --signal…). Quatro valores carregam conta de contraste no comentário: são medida, não gosto.

--color-bg #141414

Fundo. O preto quente é o chão de tudo; nunca #000.

--color-bg-deep #0d0d0d

Faixas recuadas: rodapé, gaveta, superfícies afundadas.

--color-surface #1c1c1e

Painel padrão de cards, campos e blocos.

--color-surface-raised #232326

Painel elevado em hover e foco.

--color-text #f4f3f0

Títulos, dados e ações primárias. Osso, não branco.

--color-text-muted #a5a5ac

Parágrafos, legendas, descrições.

--color-text-subtle #8d8d96

Metadados. Subido da referência #5c5c63 para passar AA também sobre painel elevado (4,8:1).

--color-line-reference #5c5c63

O valor original sobrevive aqui — fios e marcadores, onde contraste não se aplica.

--color-border rgba(255,255,255,.11)

Divisórias decorativas.

--color-border-strong rgba(255,255,255,.20)

Bordas de estado elevado.

--color-border-interactive rgba(255,255,255,.34)

Limite de chip, campo e botão. .34 é medida, não gosto: WCAG 1.4.11 exige 3:1, e .20 entrega 1,9:1. Este valor cai em 3,1:1 sobre os três fundos.

--color-accent #fb3732

O sinal. Um acento, e só ele.

--color-accent-strong #d1211d

Preenchimento que carrega texto branco: sobre o acento puro o branco dá 3,7:1; aqui, 5,3:1.

--color-accent-text #ff5c57

Vermelho como tipo sobre painel elevado: 5,2:1 contra os 4,25:1 do acento puro.

--color-warning #ffa31a

Atenção. O segundo e último acento permitido.

--color-success #4ade80

Confirmação — porque vermelho para sucesso lê como falha.

     ═══════════════════════════════════════════════════════════════════ */

  let frameId = 0;
  let last = 0;

  function awake() {
    return rings.some(ring => ring.visible && !ring.paused);
  }

  function requestFrames() {
    if (REDUCED || document.hidden || frameId || !awake()) return;
    last = performance.now();
    frameId = requestAnimationFrame(frame);
  }

  function frame(now) {
    frameId = 0;
    if (document.hidden) return;
    const dt = Math.min(.05, (now - last) / 1000);
    last = now;
    for (const ring of rings) {
      if (ring.visible && !ring.paused) ring.step(dt);
    }
    if (awake()) frameId = requestAnimationFrame(frame);
  }

  if (!REDUCED) document.addEventListener('visibilitychange', requestFrames);

  /* ═══════════════════════════════════════════════════════════════════
     2. CURSOR FOLLOWER

     A single shared element for the whole page — one gallery or six, the
     pointer only has one position. Fine pointers only: on touch there is no
     cursor to follow and the label would just sit in a corner lying.
     ═══════════════════════════════════════════════════════════════════ */
  let follower = null;
  let followerHost = null;
  const pointer = { x: 0, y: 0, ax: 0, ay: 0 };

  function ensureFollower(label) {
    if (follower || REDUCED || !FINE_POINTER) return follower;
    follower = document.createElement('div');
    follower.className = 'gallery-follower';
    follower.setAttribute('aria-hidden', 'true');
    follower.innerHTML = '<i></i><span></span>';
    follower.querySelector('span').textContent = label;
    document.body.appendChild(follower);
    pointer.ax = pointer.x = innerWidth / 2;
    pointer.ay = pointer.y = innerHeight / 2;
    addEventListener('pointermove', e => { pointer.x = e.clientX; pointer.y = e.clientY; }, { passive: true });
    return follower;
  }

  function followerStep() {
    if (!follower || !followerHost) return;
    pointer.ax = lerp(pointer.ax, pointer.x, .18);
    pointer.ay = lerp(pointer.ay, pointer.y, .18);
    follower.style.transform = `translate3d(${pointer.ax.toFixed(1)}px, ${pointer.ay.toFixed(1)}px, 0) translate(-50%, -50%)`;
  }

  /* ═══════════════════════════════════════════════════════════════════
     3. THE RING
     ═══════════════════════════════════════════════════════════════════ */
  function initGallery(root, index) {
    const stage = root.querySelector('[data-gallery-stage]');
    const track = root.querySelector('[data-gallery-track]');
    if (!stage || !track) return;

    const items = [...track.children];
    const total = items.length;
    if (total < 2) return;

    const prev = root.querySelector('[data-gallery-prev]');
    const next = root.querySelector('[data-gallery-next]');
    const status = root.querySelector('[data-gallery-status]');
    const followerLabel = root.dataset.galleryLabel || 'Ver';

    /* Reduced motion keeps the default rail: the buttons still work, they
       just scroll it. Nothing here registers a frame. */
    if (REDUCED) {
      /* O trilho conta em passos de rolagem, não em distância até o centro:
         assim a ficha 1 é a que está encostada na borda inicial, e o número
         anunciado bate com o que o botão acabou de fazer. */
      const pitch = () => {
        const first = items[0].getBoundingClientRect();
        return items.length > 1
          ? items[1].getBoundingClientRect().left - first.left
          : first.width;
      };
      const currentRailIndex = () => {
        const max = stage.scrollWidth - stage.clientWidth;
        if (max <= 0) return 0;
        /* no fim do trilho a última ficha aparece inteira mesmo com a rolagem
           parando antes do início dela */
        if (stage.scrollLeft >= max - 1) return total - 1;
        return clamp(Math.round(stage.scrollLeft / pitch()), 0, total - 1);
      };
      /* o índice é lido uma vez: rolar já muda a posição, e reler depois
         contaria o passo duas vezes */
      const scrollTo = step => {
        const idx = clamp(currentRailIndex() + step, 0, total - 1);
        stage.scrollTo({ left: idx * pitch(), behavior: 'auto' });
        announce(idx);
      };
      if (prev) prev.addEventListener('click', () => scrollTo(-1));
      if (next) next.addEventListener('click', () => scrollTo(1));
      stage.addEventListener('scroll', () => announce(currentRailIndex()), { passive: true });
      announce(0);
      return;
    }

    root.classList.add('is-live');
    stage.setAttribute('tabindex', '0');
    stage.setAttribute('role', 'group');
    stage.setAttribute('aria-roledescription', 'galeria em arco');
    if (!stage.hasAttribute('aria-label')) {
      stage.setAttribute('aria-label', `Galeria de imagens ${index + 1}`);
    }

    let pos = 0;        /* rendered index, continuous */
    let target = 0;     /* where the ring is heading */
    let dragging = false;
    let dragStartX = 0;
    let dragStartPos = 0;
    let driftAt = 0;    /* timestamp after which the ring drifts again */
    let shown = -1;

    const ring = {
      visible: false,
      paused: false,
      step(dt) {
        if (!dragging && performance.now() > driftAt) target += dt * DRIFT_PER_SECOND;
        pos = lerp(pos, target, .085);
        place();
        if (followerHost === root) followerStep();
      }
    };
    rings.push(ring);

    /* medido no palco, não na janela: a galeria costuma viver dentro de uma
       coluna, e um raio tirado da largura da janela espalha o anel para fora
       do recorte, deixando só três fichas visíveis */
    const radius = () => clamp((stage.clientWidth || innerWidth) * .46, 300, 560);

    function place() {
      const R = radius();
      items.forEach((item, i) => {
        /* shortest signed offset, so the ring wraps instead of unrolling */
        let d = i - pos;
        d = ((d % total) + total + total / 2) % total - total / 2;

        const a = d * SPREAD * Math.PI / 180;
        const ca = Math.cos(a);
        const x = Math.sin(a) * R;
        const z = (ca - 1) * R * DEPTH_PULL;
        const y = (1 - ca) * R * LIFT;
        const depth = Math.pow(Math.max(0, ca), 3);
        const scale = .4 + depth * .6;
        const front = Math.abs(d) < .5;

        item.style.transform =
          `translate(-50%, -50%) translate3d(${x.toFixed(1)}px, ${y.toFixed(1)}px, ${z.toFixed(1)}px) scale(${scale.toFixed(3)})`;
        item.style.opacity = String(clamp(depth * 2.4, 0, 1));
        item.style.zIndex = String(Math.round(depth * 100));
        /* a queda de brilho precisa morder cedo: uma captura de tela clara em
           segundo plano rouba o olho da ficha da frente se só escurecer 12% */
        item.style.filter = depth < .92 ? `brightness(${(.34 + depth * .72).toFixed(2)})` : '';
        /* only the facing card answers the pointer, so a drag never grabs a
           card the reader cannot see */
        item.style.pointerEvents = front ? 'auto' : 'none';
        item.classList.toggle('is-front', front);
        item.toggleAttribute('inert', !front);
      });

      const idx = ((Math.round(pos) % total) + total) % total;
      if (idx !== shown) {
        shown = idx;
        items.forEach((item, i) => {
          if (i === idx) item.setAttribute('aria-current', 'true');
          else item.removeAttribute('aria-current');
        });
        announce(idx);
      }
    }

    function announce(idx) {
      if (!status) return;
      const safe = clamp(idx, 0, total - 1);
      const title = items[safe].dataset.galleryTitle || items[safe].querySelector('img')?.alt || '';
      status.textContent = title
        ? `${safe + 1} de ${total} — ${title}`
        : `${safe + 1} de ${total}`;
    }

    function go(step) {
      target = Math.round(target) + step;
      driftAt = performance.now() + RESUME_DRIFT_MS;
      requestFrames();
    }

    if (prev) prev.addEventListener('click', () => go(-1));
    if (next) next.addEventListener('click', () => go(1));

    stage.addEventListener('keydown', e => {
      if (e.key === 'ArrowLeft') { e.preventDefault(); go(-1); }
      else if (e.key === 'ArrowRight') { e.preventDefault(); go(1); }
      else if (e.key === 'Home') { e.preventDefault(); target = 0; driftAt = performance.now() + RESUME_DRIFT_MS; requestFrames(); }
      else if (e.key === 'End') { e.preventDefault(); target = total - 1; driftAt = performance.now() + RESUME_DRIFT_MS; requestFrames(); }
    });

    /* The drift is a background motion, not a slideshow: it stops while the
       reader is reading, which is what focus and hover tell us. */
    /* ao receber foco o anel encosta no rosto mais próximo em vez de congelar
       no meio do caminho: quem chegou pelo teclado precisa de uma ficha da
       frente definida, não de duas pela metade */
    stage.addEventListener('focusin', () => {
      driftAt = Infinity;
      target = Math.round(target);
      requestFrames();
    });
    stage.addEventListener('focusout', () => { driftAt = performance.now() + RESUME_DRIFT_MS; });

    stage.addEventListener('pointerdown', e => {
      dragging = true;
      dragStartX = e.clientX;
      dragStartPos = target;
      driftAt = Infinity;
      root.classList.add('is-dragging');
      stage.setPointerCapture(e.pointerId);
      requestFrames();
    });
    stage.addEventListener('pointermove', e => {
      if (dragging) target = dragStartPos - (e.clientX - dragStartX) / DRAG_DIVISOR;
    });
    function endDrag() {
      if (!dragging) return;
      dragging = false;
      root.classList.remove('is-dragging');
      target = Math.round(target);     /* snap to the nearest face */
      driftAt = performance.now() + RESUME_DRIFT_MS;
    }
    stage.addEventListener('pointerup', endDrag);
    stage.addEventListener('pointercancel', endDrag);

    /* Horizontal intent only. Claiming vertical wheel would trap the page. */
    let wheelTimer = 0;
    stage.addEventListener('wheel', e => {
      if (Math.abs(e.deltaX) <= Math.abs(e.deltaY)) return;
      e.preventDefault();
      target += e.deltaX / 240;
      driftAt = Infinity;
      clearTimeout(wheelTimer);
      wheelTimer = setTimeout(() => {
        target = Math.round(target);
        driftAt = performance.now();
      }, 700);
      requestFrames();
    }, { passive: false });

    if (FINE_POINTER) {
      ensureFollower(followerLabel);
      stage.addEventListener('pointerenter', () => {
        followerHost = root;
        if (follower) follower.classList.add('is-on');
      });
      stage.addEventListener('pointerleave', () => {
        if (followerHost === root) followerHost = null;
        if (follower) follower.classList.remove('is-on');
      });
      stage.addEventListener('pointerdown', () => follower && follower.classList.add('is-press'));
      stage.addEventListener('pointerup', () => follower && follower.classList.remove('is-press'));
    }

    new IntersectionObserver(entries => {
      ring.visible = entries[0].isIntersecting;
      requestFrames();
    }, { rootMargin: '160px' }).observe(root);

    addEventListener('resize', place);
    place();
    requestFrames();
  }

  function boot() {
    document.querySelectorAll('[data-gallery]').forEach(initGallery);
  }

  if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', boot);
  else boot();
})();

Regras

O que separa um sistema de uma folha de estilo. Estas dez valem mais que qualquer componente — um componente se substitui, uma regra quebrada contamina tudo o que vier depois.

Comece pelos tokens

Use uma cor, passo de espaço, raio, escala e curva que já existam antes de inventar um valor. Um valor novo precisa justificar por que os dezesseis existentes não serviam.

Roxo é proibido

Convenção do sistema, não preferência do dia. Os acentos são --signal (vermelho) e --amber. Nada de violeta, índigo ou gradiente arco-íris.

Um acento por vez

O vermelho aponta uma coisa por tela. Se duas coisas estão em vermelho, nenhuma está.

Contraste é conta, não olho

Quatro tokens carregam a matemática WCAG no comentário. Se mudar o valor, refaça a conta — não "arrume" o número porque ele parece estranho.

Estados são completos

Toda interação considera hover, foco, desabilitado, carregando, erro, sucesso e movimento reduzido. Faltando um, o componente não está pronto.

O conteúdo lidera

Superfície apoia informação. Não embrulhe texto em card só para preencher grade — nem toda coisa é card, e card dentro de card nunca está certo.

Teste em 320px

A composição pode mudar; a informação não pode sumir. Alvo de toque mínimo é --tap, 44px, inclusive para um chip que virou link.

Cada seletor uma vez

A ordem da cascata é contrato: tokens, reset, tipo, primitivas, componentes, reveal, utilidades, movimento reduzido. O valor final de um componente mora na regra dele, não num bloco de correção no fim do arquivo.

Legível antes de animado

Toda animação vive sob .js. Sem script, o conteúdo aparece inteiro e parado. Se um elemento só faz sentido depois de animar, ele está errado.

Versione o que a página pede

Se houver CDN na frente, ele ignora o no-cache do servidor. Sem ?v= a página nova recebe o arquivo velho — e você passa a tarde caçando um bug que é cache.

O que ficou de fora

A folha é o sistema, não o site. Estas peças moram no portfólio porque são daquele projeto — se você precisar de alguma, copie de lá conscientemente, não por engano.

Herói e colagem

Composição de capas com paralaxe de ponteiro, amarrada ao conteúdo daquela abertura.

Cartões de projeto

.box--media com captura emoldurada e capa girada. Formato editorial específico.

Cabeçalho e gaveta

Navegação fixa, burger, trava de foco e scroll-spy. Depende dos ids daquela página.

Rodapé e faixa

Marquee em laço contínuo e relógio de fuso. Conteúdo daquele rodapé.

Skins de seção

Onde uma seção reafirma um componente por ser ela própria o assunto.

Folhas do catálogo

O .ds-* que desenha a página de catálogo do design system.
